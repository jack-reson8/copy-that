# Copy That

[English](README.md) | 简体中文

**你说要做什么，agent 回一句"Copy that"，然后做得有品味。**

六个开源工具，给做东西、发东西的人用，支持 Claude Code 和 Codex。MIT 协议，免费。

## 一次装全

**Claude Code**
```
/plugin marketplace add jack-reson8/copy-that
/plugin install pro-motion@copy-that
```
把名字换成下表任意一个即可，每个插件从它自己的仓库安装。

**Codex**
```bash
codex plugin marketplace add https://github.com/jack-reson8/copy-that.git
codex plugin add pro-motion@copy-that
```

## 为什么叫 Copy That

copy 是广告文案；"Copy that" 是接到 brief 后那句"收到，马上办"；copy 也是复制，装上就能用。三层意思都成立。
